## Contributing to Archiverse

Thank you for your interest in contributing to Archiverse! I welcome contributions from the community to help improve the app and enhance the user experience. While the API code is not open source, you can still contribute to the UI and local database portions of the app.

### Getting Started

1. Fork the repository
2. Clone your fork locally
3. Install dependencies
4. Create a new branch for your changes
5. Make your changes and test them
6. Submit a pull request

### Development Setup

Install the Flutter SDK if you haven't already. Follow the [Flutter installation guide](https://flutter.dev/docs/get-started/install) for your platform.

After cloning the repository, navigate to the project directory and run:

```bash
flutter pub get
```

This will install the necessary dependencies for the project. To get started, follow the Flutter documentation on [building and running apps](https://flutter.dev/docs/get-started/test-drive).

### Code Style Guidelines

- Follow existing code formatting - the project uses Dart's recommended style which is also used in the official Flutter VS Code extension.
- Use meaningful variable and function names - shorthands aren't discouraged, but they don't improve performance at all (because Dart is compiled)! Make sure your code is readable instead.
- Add comments for complex logic - Keep your code DRY (Don't Repeat Yourself) - avoid duplicating code by creating reusable functions or widgets.
- Ensure your code is well-tested - If necessary, ping me (@TenSeventy7) when you submit a pull request so I can review it promptly.

### Community Guidelines

- Be respectful and inclusive
- Provide constructive feedback
- Help others when possible
- Follow the project's code of conduct

Thank you for contributing to Archiverse! 🚀
